\emergencystretch=2em

This appendix documents supplementary diagnostics for the Random Forest and
RoBERTa\slash BERT components of the thesis. The Random Forest is used in two ways.
First, the same-meeting classifier produces \rfscore{} for the RQ1
market-reaction regressions. Second, expanding-window Random Forest regressors
produce genuine out-of-sample forecasts for RQ2. RoBERTa\slash BERT is used as a
sentence-level benchmark that is aggregated to a document-level score and then
used in both RQ1 and RQ2.

The feature table confirms that the Random Forest learns both direct policy
action phrases and broader institutional language. The top features should not
be read mechanically as a new structural dictionary. They are predictive
features for a classifier trained on realised rate-decision signs. The feature
inspection is therefore useful for interpretation and diagnostics, not for
claiming causal linguistic primitives.

The remaining limitation is that feature importance cannot fully separate
economic stance from institutional regularities. \Cref{tab:a3_rf_leakage_caution}
lists examples of high-importance or visible features that require caution.
Some are close to boilerplate or speaker/committee structure rather than pure
monetary-policy tone. This does not invalidate the RF score for prediction, but
it limits the structural interpretation of individual bigrams. The blocklist
therefore improves the classifier but does not turn RF feature importance into
a complete economic dictionary.

\section{RoBERTa\slash BERT diagnostics}
\label{app:a3_bert_diagnostics}


The RoBERTa\slash BERT score is used as a contextual sentence-level benchmark. It is
not treated as a fully institution-specific structural model of ECB language.
The key interpretation issue is calibration and domain transfer. A sentence
classifier trained on annotated monetary-policy language may capture general
hawkish/dovish semantics, but the mapping from sentence tone to monetary-policy
stance can differ across central banks, document types, and policy regimes. The
RoBERTa\slash BERT results should therefore be read as an external semantic benchmark
rather than as manually verified ground truth.

same way.

\subsection{Illustrative Expanding-Window Feature Importance}
\label{app:rf_single_xw_importance}

The main expanding-window Random Forest procedure stores out-of-sample
predictions but does not save variable importance at every forecast step. As an
interpretability diagnostic, one expanding-window forecast is therefore rerun
with impurity-based variable importance enabled. The diagnostic uses the same
chronological logic as the RQ2 forecasting exercise: the TF--IDF vocabulary is
fitted only on the training window, Lasso feature pre-selection is performed
only on information available before the forecasted meeting, and the Random
Forest is then used to predict one held-out observation.

The default diagnostic uses FOMC statements, the next-meeting rate-decision
target \texttt{bps\_next}, and the full cleaned text input \texttt{text\_clean}.
This case is chosen because the FOMC statement expanding-window Random Forest
is one of the strongest RQ2 forecasting specifications in the main Results
chapter. The output is saved by the R pipeline under the prefix
\texttt{rf\_xw\_single\_fomc\_stmt\_bps\_next}.

The diagnostic should be interpreted cautiously. The reported feature
importance is model-level importance for the Random Forest fitted at that
forecast step. It is not a local causal attribution for the individual
prediction and it is not a full expanding-window importance series. Its purpose
is only to illustrate the type of bigram information used by the
expanding-window Random Forest in the RQ2 forecasting exercise.

\section{Implementation notes}
\label{app:a3_implementation_notes}

All Random Forest models are estimated separately by corpus. The same-meeting
classification models use bigram TF--IDF features, the blocklist in
Appendix~\ref{app:a1_blocklist}, Lasso pre-selection, and class-balanced
sampling. The expanding-window forecasting models rebuild the vocabulary and
refit the model using only information available before the forecasted meeting.
This distinction is important: OOB classification performance is a descriptive
same-meeting diagnostic, while the expanding-window results are the genuine
forecasting exercise.
