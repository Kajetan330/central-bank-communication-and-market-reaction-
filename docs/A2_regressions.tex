This appendix reports supplementary regression and forecast diagnostics for the
final pipeline. The tables are designed to support Chapter~\ref{ch:results}
without overloading the main text. All market-reaction regressions use HC1
robust standard errors. FOMC specifications control for MP1; ECB specifications
control for OIS\_MP1. Positive text scores denote more hawkish communication.

\section{Interpretation notes}
\label{app:a2_interpretation_notes}

The tables above should be read together with the main Results chapter. The
large $R^2$ values in rate-decision forecasting specifications partly reflect
policy inertia. The direct out-of-sample $R^2$ table is therefore the stricter
forecasting diagnostic, while the incremental-$R^2$ table answers a different
question: whether the text forecast adds explanatory power to an inertia-only
regression over the same observations. This distinction is central to the
interpretation of RQ2.
